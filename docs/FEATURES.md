# Features

## Phase 1 — Live
- Premium Gen-Z homepage (11 sections)
- Transparent → glassmorphism sticky header
- 3D hero with mouse-tracked tilt and floating badges
- Animated count-up stats strip
- Tilt-card services grid
- Rotated experience/WhyUs cards
- Mock AI receptionist chat preview
- Before/after gallery
- Snap-scroll mobile reviews carousel
- Pulsing emergency CTA
- Floating chat widget (consent gate → full chat)
- Quick replies and canned AI responses
- Typing indicator with animated dots
- Lenis smooth scroll

- `useReducedMotion` support throughout
