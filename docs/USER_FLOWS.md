# User Flows

## New Patient → Book via Chat
1. Patient sees floating chat button (pulsing blue)
2. Clicks → ConsentGate appears (checkbox + disclaimer)
3. Checks consent → "Start Chat with Ava" enables
4. Chat opens with Ava greeting
5. Patient clicks "New patient" quick reply
6. Ava explains first-visit package, asks to book
7. Patient provides name/phone → lead saved
8. Ava confirms and provides clinic phone as backup

## Emergency Patient
1. Patient clicks "Emergency pain" quick reply
2. Ava immediately surfaces phone number (604) 555-0192
3. Same-day slot mention — call to action to call directly

## Book via Homepage CTA
1. Patient clicks "Book Appointment" in Header or Hero
2. Scrolls to #book section (FinalCTA)
3. Clicks "Book Appointment" → future booking modal or Calendly

## Admin Reviews Lead
1. Admin navigates to /admin/leads
2. Sees table of leads with name, phone, source, date
3. Clicks lead → views associated conversation (Phase 2)
4. Marks appointment as confirmed
