# Project Brief

**Product:** Ava Dental Studio — Premium Dentist Website + AI Receptionist Platform
**Goal:** A sellable SaaS product for dental clinics combining a conversion-focused marketing site with an embedded AI receptionist and admin dashboard.

## Phases

| Phase | Scope | Status |
|-------|-------|--------|
| 1 | Public website UI (homepage, all sections, chat widget) | ✅ Complete |
| 2 | Working chat widget with lead capture + Supabase | 🔜 Next |
| 3 | Admin dashboard (leads, appointments, conversations, triage) | 🔜 Stubbed |
| 4 | Voice AI agent (Vapi / Retell AI) | 🔜 Future |

## Target Client
Dental clinics that want a premium digital presence and want to automate their front-desk with AI.
